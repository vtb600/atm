Chuyển không dấu & tách địa chỉ mới

Tải file Excel lên, công cụ sẽ tạo file kết quả mới gồm 5 cột đã chuyển không dấu và tách địa chỉ.

📄
Kéo thả file Excel vào đây, hoặc bấm để chọn file
.xlsx / .xls
File kết quả sẽ có các cột:
A ho_ten_khong_dau — họ tên đã bỏ dấu
B dia_chi_moi_khong_dau — địa chỉ đã bỏ dấu, đã xoá dấu *
C tinh_thanh — phần cuối cùng (vd: Lam Dong)
D xa_phuong — phần kế cuối (vd: Xa/Phuong ...)
E con_lai — phần còn lại phía trước
